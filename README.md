# Hello!

### This branch contains a version of my Multiplication Table Project made using flexbox!

I found this exercise quite hard at first because it was my first time working with Javascript.

I got stuck on rather simple obstacles, like mixing up the names of my variables and elements when referencing them in js and css, which really slowed me down for a while.
Another hurdle came with styling my column elements because I couldn't get them to align properly at first. I thought I needed to create a div within a div somehow before I realized I could just give them each a set width and height. In the end, most of the challenges I faced were really quite easy to solve; the solutions just flew over my head. 

My biggest takeaway from this assignment was **HTML, CSS, and Javascript can be used together to create complex programs.** You have to be able to leverage all three languages in order to make your work look good and run well. You can't rely on only one or two of these languages.
